# 0.0.21 统一笔记库与按钮交互

用户授权：按照前一轮按钮评审优化全部交互；保持已确认的数据含义，需要新的产品决策时再询问。

左侧“AI 笔记”是打开右栏的菜单，右栏是展示位置。内部原有手工列表与全量库已在原生右栏统一。旧独立组件保留供旧上下文与组件级回归使用，原生右栏不显示第二套列表、刷新手工列表或打开/关闭库按钮。

## 操作规则

- 默认显示笔记库。导航可切换笔记、回收站、标签、备份，新建笔记在同一右栏编辑。
- 新建保存后刷新统一列表；摘录保存同样通知打开的列表。
- 范围、类型和标签即时查询；搜索输入需 Enter 或搜索按钮提交。即时标签查询基于已应用条件，不提交未应用的关键词/高级条件。高级筛选仍显式应用，重置恢复默认条件。
- 本地日期时间输入转换为 ISO 绝对时间。保持原有时间范围比较，未改成整日范围。
- 卡片主要显示详情和来源；复制 Markdown、下载、写入输入框、编辑和删除在“更多”中。
- 选择后在列表上方显示批量操作条；保留筛选外已选数量说明。修改前仍读取并确认影响预览。
- 删除写入 deletedAt，可恢复。永久删除只对回收站笔记开放，必须确认，不改现有领域删除规则。
- 为划线补充正文在一次 notes/edit 中变为 note，保留 ID、引用、锚点、来源和标签关系。空白正文不触发变更类型；非空正文通过原有字段限额和版本校验。
- 快捷标签在批注正文存在时只选择标签并返回编辑器；任意保存路径均保留已有批注。丢弃正文需确认。
- 标签逐行提供重命名、合并、删除；合并/删除仍读取影响预览并确认。删除标签不会删除笔记。
- 编辑器允许继续编辑、关闭保留草稿，或明确丢弃修改。存在待确认提交时不提供丢弃动作。
- 弹窗支持 Escape 触发可用取消操作。提交结果不确定时保留原意图，可在确认弹窗内按同一 requestId 重试，或关闭弹窗并保留待确认操作。COMMIT_UNKNOWN 仍执行既有停写规则，不自动重试。
- 成功反馈为单一短提示；失败提示保留至下一次操作。保留写入输入框、恢复归档会话、永久删除等必要确认。
- 备份页面只提供完整 JSON 下载，说明包括笔记、标签和回收站；未开放未完成的坏库恢复/备份替换流程。

## 自动验证与边界

定向测试先复现“正文被快捷保存丢弃”和“有正文直接取消”，修复后通过。新增领域回归验证补充正文只修改原笔记，并保留来源字段。

本轮浏览器采用生产 Client、真实 notebook service 和内存存储。宿主侧栏、会话导航、输入框及 HTTP carrier 为显式测试替身，不属于真实 Desktop 验收。测试只使用 Synthetic 数据，不访问用户 Profile。

验证状态以本轮最终执行结果为准：check、单元、集成、运行时、pack:check、diff 检查，以及五组浏览器场景。新增场景主动让真实 service 完成提交后返回畸形回包，再点击弹窗内同请求重试，分别覆盖笔记操作和标签删除，核对 requestId 不变。

未安装、启用或重启 Desktop。未改变传输/认证入口，未注册官方 changes.summary；该宿主接口的 404 不属于 Notebook 路由。真实侧栏入口位置、实际载入版本、重启读回与宿主来源跳转仍需用户在新包中验收。
